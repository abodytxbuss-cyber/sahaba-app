# سحابة — رحلة السينما ☁️

تطبيق ويب عربي سينمائي بأسلوب رحلة مراحل (مثل ألعاب المغامرات):
- 🗺️ **ماب عمودي** — مراحل ورا بعض، كل مرحلة تلمع عند إنجازها وتفتح التالية.
- ⭐ **نقاط ومستويات** — كل مشاهدة = +XP، ارتقِ من غيمة إلى سماء مفتوحة.
- 🎬 **46 فيلماً** كاملة التفاصيل (وصف، مدة، طاقم، تقييم) + كتالوج سحابة الحيّ.
- 📚 مكتبة (شاهدتها / لاحقاً) محفوظة في المتصفح.

## التشغيل

```bash
npm start
# ثم افتح http://localhost:8080
```

السيرفر بواجهة Node فقط (بدون مكتبات خارجية) ويوكل واجهة سحابة/Stremio مع دمج النسخة الاحتياطية `data/movies.json` تلقائياً.

## إعدادات البيئة

| متغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | منفذ الخادم | `8080` |
| `SOURCE_SITE` | مصدر الكتالوج الحيّ | `https://sahaba.onrender.com` |
