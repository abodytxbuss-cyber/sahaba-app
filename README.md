# سحابة ☁

تطبيق سينمائي عربي باتجاه RTL: اكتشاف الأفلام والمسلسلات، رحلة من المراحل، نقاط خبرة وإنجازات، مكتبة محلية، وإضافات متوافقة مع بروتوكول Stremio. لا يحتوي على أي مصدر مشاهدة مدمج.

## الكتالوجات المعبأة — الإصدار 3.1

تضم النسخة الحالية **22 كتالوجاً، و2547 فيلماً فريداً و349 مسلسلاً فريداً** من Cinemeta، مع 665 ربطاً لملصق محلي أو بديل عند غياب الصورة. تظهر الأرفف مباشرة من البيانات المحلية، ويحدّث التطبيق الرائج والمسلسلات في الخلفية. تشمل الكتالوجات الرائج، الأعلى تقييماً، سنوات 2026–2024، الأكشن، المغامرة، الرسوم المتحركة، الكوميديا، الجريمة، الدراما، العائلة، الفانتازيا، الرعب، الغموض، الرومانسية، الخيال العلمي، التشويق، الوثائقيات والحرب.

اختر «عرض الكل» لأي رف لفتح كتالوجه الكامل مع البحث داخله وتحميل المزيد. تعرض صفحة إصدارات سحابة جميع الأفلام الـ46 دون تقييدها بمراحل الرحلة. حجم العرض الأولي 48 بطاقة لتبقى الصفحة خفيفة.

لتحديث النسخة المحلية يدوياً قبل النشر:

```sh
npm run refresh:catalogs
```

يحفظ التحديث بيانات العرض المختصرة، ويتجنب إعادة تنزيل الملصقات الموجودة. المراحل السابقة مثبتة في `data/journey.json` ولا تتغيّر مع التحديث. التعريفات والأعداد في `data/collections.json`.

يوجد ملف `render.yaml` جاهز لخدمة Node مجانية على فرع `master`؛ يتحقق من الاختبارات أثناء البناء ويستخدم `/health` لفحص الخدمة. إذا كانت لديك خدمة Render سابقة اربطها بالمستودع وحدّثها عوضاً عن إنشاء خدمة مكررة.

## التشغيل

تحتاج Node.js 20 أو أحدث. لا توجد حزم يجب تثبيتها؛ مكتبة hls.js الوحيدة موجودة محلياً داخل assets مع ترخيصها.

```powershell
cd "C:\Users\MSi\Documents\Default Project\sahaba-app"
npm start
```

افتح http://localhost:8080. لا تفتح index.html مباشرةً عبر file:// لأن الوحدات وطلبات البيانات تحتاج خادم HTTP.

إذا كان المنفذ مستخدماً، أغلق نسخة سحابة السابقة أو استخدم:

```powershell
$env:PORT="8088"
npm start
```

إذا منعت سياسة PowerShell تشغيل npm.ps1، استخدم `npm.cmd start` أو `node server.js`.

## أول إضافة Stremio

1. انسخ رابط `manifest.json` من مزوّد الإضافة بعد إكمال إعداداتها إن احتاجت ذلك.
2. افتح **إضافاتي**، ألصق الرابط، واضغط **إضافة إلى سحابة**. يقبل التطبيق أيضاً روابط `stremio://` ويحوّلها إلى HTTPS.
3. تظهر الكتالوجات في الرئيسية. الإضافات التي تتطلب البحث تظهر نتائجها في صفحة اكتشف.
4. افتح فيلمًا واضغط **شاهد الآن**، ثم اختر المصدر والجودة. للمسلسلات اختر الموسم والحلقة.
5. تستطيع تعطيل الإضافة أو حذفها من الصفحة نفسها.

يمكن تجربة `https://v3-cinemeta.strem.io/manifest.json` للتحقق من قراءة كتالوجات إضافة؛ Cinemeta لا يوفّر مصادر تشغيل. لتشغيل فيديو تحتاج إضافة تُرجع روابط فيديو مباشرة. لا يلزم تثبيت إضافة للحصول على كتالوج Cinemeta الأساسي.

يدعم المشغل MP4 عندما يدعم المتصفح ترميزه، وHLS عبر hls.js أو دعم Safari الأصلي، وترجمات VTT وSRT المسموح بتحميلها عبر CORS. روابط التورنت وinfoHash ليست فيديو مباشراً؛ تظهر كمصادر غير مدعومة دون تشغيلها. الروابط المحمية بـDRM أو التي تتطلب ترويسات خاصة أو كوكيز ليست مدعومة. دعم رابط مباشر لا يعني دعم جميع الترميزات داخل حاويته. الإعلانات الدعائية تُعرض داخل YouTube مع رابط بديل عند منع التضمين.

## العربية في المشغّل — الإصدار 3.2

- يُضاف **OpenSubtitles v3** المجاني مرة واحدة عند فتح النسخة الجديدة، ويظهر في «إضافاتي». يمكنك تعطيله أو حذفه؛ لن يُعاد تفعيله بعد ذلك.
- اختيار العربية تلقائياً مفعّل افتراضياً، ويمكن إيقافه من المشغّل. تُرتب النسخ المعلنة بدبلجة عربية أولاً؛ لا تُعد عبارة «ترجمة عربية» دليلاً على دبلجة.
- يختار المشغّل مسار الصوت العربي في HLS أو المسارات التي يكشفها المتصفح، ويعرض قائمة للتبديل اليدوي. بعض حاويات MP4/MKV لا تكشف مساراتها في كل المتصفحات.
- تُحمّل ترجمة عربية تلقائياً من الإضافة أو من ترجمات المصدر. تُفضّل مطابقة اسم الإصدار عند توفره، لكن التطابق والتوقيت ليسا مضمونين؛ اختر نسخة أخرى أو عدّل التوقيت بالثواني.
- يدعم ملفات SRT وVTT محلية حتى ٢ ميغابايت، بدون رفع الملف لأي خدمة. تُزال أوامر تنسيق ASS غير المتوافقة ويُدعم UTF-8 وUTF-16 وترميز العربية القديم Windows-1256.
- عند تعطل الترجمة أو غيابها تظهر رسالة واضحة وزر إعادة المحاولة؛ يستمر الفيديو مستقلاً عنها. يمكن اختيار «بدون ترجمة» يدوياً.
- هذا اختيار لترجمات ودبلجات موجودة فعلاً؛ لا يترجم الكلام آلياً، ولا يولّد دبلجة، ولا يضمن وجود العربية لكل فيلم. لا توجد خدمة ترجمة مدفوعة أو مفاتيح API مطلوبة.

## كيف تعمل الرحلة؟

- القائمة المطلوبة تضم 46 فيلماً، وهي موجودة كاملة في `data/movies.json` ببيانات Cinemeta وتفاصيل عربية محلية. لتطبيق شرط 10–15 عنواناً في المرحلة، قُسمت إصدارات سحابة إلى مراحل من **12، 12، 11، 11** فيلماً، تبدأ بالمرحلة الأولى.
- تتبعها مراحل السنوات من الأحدث للأقدم ثم المسلسلات. بُني ترتيبها من النسخة المحلية الثابتة حتى لا يتغير تقدم المستخدم بتغير الترند اليومي.
- تفتح المرحلة التالية عندما تُشاهد كل عناوين السابقة. زيارة صفحة مرحلة مقفولة عبر الرابط لا تتجاوز القفل.
- أول اكتمال لفيلم أو حلقة يمنح **50 XP ونجمة**. يحدث عند الوصول إلى 90% أو نهاية الفيديو، أو عند تأكيد **سجلته كمُشاهد** يدوياً. التأكيد اليدوي للمسلسل يسجله كاملاً، بينما التشغيل التلقائي لا يسجل المسلسل مكتملًا حتى تنتهي جميع حلقاته العادية التي عُرضت.
- لا يمنح مجرد فتح المشغّل نقاطاً، ولا تمنح إعادة المشاهدة نقاطاً مكررة.
- المستويات: **غيمة جديدة** من البداية، **سحابة ذهبية** عند 500 نقطة، **سماء مفتوحة** عند 1500 نقطة.
- الإنجازات: أول فيلم، عشرة أفلام، وإكمال مرحلة. يعرض زر XP تفاصيلها.

## البيانات والترجمة والاتصال

- الاتصال بـCinemeta والإضافات مباشر من المتصفح أولاً.
- مسارات الكتالوج: `/catalog/movie/top.json` و`/catalog/series/top.json`؛ البحث عبر `search=` والتصنيف عبر `genre=`؛ الصفحة التالية تزيد `skip` بمقدار 100.
- تصفية السنة تستخدم كتالوج Cinemeta المخصص: `/catalog/movie/year/genre=2026.json` لأن `top/genre=` مخصص للتصنيف. عند جمع السنة والتصنيف، تُصفّى النتائج المستلمة محلياً. زر المزيد يفحص الصفحة التالية حتى لو أعاد الخادم أقل من 100 عنصر؛ بعض الصفحات الحالية تعيد نحو 50 عنصراً. قد توجد نتائج مطابقة في صفحات لاحقة.
- التفاصيل عبر `/meta/<type>/<id>.json`، ومصادر الحلقات عبر معرف الحلقة نفسه مثل `tt0944947:2:1`، مع ترميز المعرف ضمن المسار.
- يراعي التطبيق `types` و`idPrefixes` وصيغ `resources` المختصرة والموسعة. الكتالوج ذو حقل مطلوب بقائمة خيارات يستخدم أول خيار افتراضياً. الحقول المطلوبة الحرة غير `search` تحتاج رابط إضافة مُعدًّا أو دعماً خاصاً ولا يجري اختلاق قيمة لها.
- مدة كاش الطلبات في الذاكرة وlocalStorage: الكتالوج 30 دقيقة، التفاصيل والـmanifest يوم، المصادر دقيقتان، الترجمات 5 دقائق. الحد 80 إدخالاً بالذاكرة و40 في التخزين المحلي. إعادة المحاولة تتجاوز الكاش.
- النسخة الاحتياطية المحلية للكتالوج مستقلة عن مدة الكاش، وتظهر عند فشل الاتصال مع تنبيه وإعادة محاولة. ملف `data/posters.json` يربط أكثر من 300 ملصق محفوظ محلياً؛ الصور التي لا تتوفر تُستبدل بملصق سحابة.
- يحفظ Service Worker واجهة التطبيق والأصول التي زرتها لفتحها لاحقاً بلا اتصال بعد أول زيارة ناجحة. لا يخزّن ملفات الفيديو أو بيانات مصادر المشاهدة فيه. أول فتح على جهاز جديد يحتاج وصولاً إلى الخادم.
- `data/ar-titles.json` يحتوي 124 عنواناً عربياً. أضف أي عنوان جديد بصيغة `{ "tt1234567": { "ar": "العنوان العربي", "en": "English title" } }`. الواجهة عربية بالكامل، وبيانات الإضافات التي لا تملك ترجمة محلية تظهر بلغتها الأصلية؛ لا توجد خدمة ترجمة آلية أو بيانات مترجمة مختلقة.
- المكتبة والمشاهدات والنجوم والإضافات خاصة بهذا المتصفح، ولا تتزامن مع أجهزة أخرى. عند امتلاء التخزين يظهر تنبيه؛ لا تُرسل مكتبتك إلى خادم حسابات.

## الوكيل الاختياري

يعمل خادم Node بواسطة `node:http`، دون Express. يخدم الملفات العامة فقط، ويدعم `/health` و`/api/proxy?url=...` مع CORS وكاش 5 دقائق وحد أقصى 100 استجابة و5 MB لكل استجابة.

الوكيل يسمح بـCinemeta فقط افتراضياً؛ طلبات الإضافات الأخرى المباشرة تعمل إذا كان مزوّدها يدعم CORS. للسماح بوكيل لإضافة موثوقة لا تدعم CORS:

```powershell
$env:PROXY_HOSTS="addon.example.com,another.example.com"
npm start
```

ضع أسماء المضيفين فقط دون البروتوكول. يسمح الوكيل بـHTTPS وملفات JSON فقط، ولا يتبع التحويلات إلا إلى مضيف مسموح بعد فحصه، ولا ينقل ملفات الفيديو أو الترجمات. لا تضف مضيفاً داخلياً أو غير موثوق إلى القائمة. لتعطيل الوكيل: `ENABLE_PROXY=false`.

## النشر

### GitHub وRender

1. ارفع ملفات المشروع كاملة إلى مستودع GitHub، بما فيها `assets` و`data`.
2. في Render أنشئ **Web Service** واربط المستودع. اختر بيئة Node.
3. أمر البناء: `npm install --omit=dev`، وأمر البدء: `npm start`، ومسار فحص الصحة: `/health`.
4. Render يمرر متغير `PORT` تلقائياً. يدعم الخادم أيضاً `HOST` عند الحاجة.
5. أضف `PROXY_HOSTS` فقط إذا احتجت الوكيل لإضافات معينة.

### GitHub Pages / استضافة ثابتة

يمكن نشر الملفات نفسها دون بناء. روابط الصفحات تستخدم hash لذا تعمل داخل مجلد المستودع. الفيديو والكتالوجات يتصلان مباشرة بمزوّديهما؛ **وكيل Node لا يعمل على GitHub Pages**. استخدم Render إذا احتجته. يعمل Service Worker على HTTPS أو localhost. عند تحديث الواجهة، غيّر إصدار `CACHE` في `sw.js` لتحديث النسخة المحفوظة بوضوح.

## الملفات

- `index.html` و`style.css`: الواجهة المتجاوبة، الخطوط المحلية، التركيز والتنقل والألوان.
- `app.js`: الصفحات والرحلة والبحث وإدارة الإضافات.
- `js/api.js`: بروتوكول Stremio وطلبات الشبكة.
- `js/store.js`: المكتبة والكاش والنقاط.
- `js/player.js`: الفيديو والترجمات واستئناف المشاهدة.
- `js/ui.js`: مكونات العرض والتنقل بأسهم الريموت.
- `server.js`: الخادم والوكيل الاختياري.
- `sw.js`: غلاف التطبيق للعمل بلا اتصال.
- `data/`: الأفلام والعناوين العربية والكتالوجات وخرائط الملصقات الاحتياطية.
- `assets/`: الملصقات والخلفيات والخطوط وhls.js وتراخيص المكتبات والخطوط.
- `tests/core.test.js`: اختبارات آلية بلا اعتماديات إضافية.
